# Brief de Marca · Redes Sociales

Este es un proyecto independiente para recolectar información de clientes potenciales mediante un cuestionario detallado (Brief). El formulario está diseñado para ser integrado en WordPress (por ejemplo, con el módulo de código de Divi) o usado como una página HTML autónoma.

## Características principales

- **Formulario interactivo**: Secciones organizadas y diseño premium.
- **Envío directo por Email**: Integrado con [FormSubmit](https://formsubmit.co/) para enviar respuestas a `hola@jkwilches.com`.
- **Confirmación AJAX**: Envía la información sin recargar la página y muestra un mensaje de éxito.
- **Validación visual**: Los campos seleccionados (radio/checkbox) cambian de color para una mejor experiencia de usuario.
- **Diseño Responsive**: Adaptado para dispositivos móviles y escritorio.

## Uso

1. Copia el código de `brief-fisioterapia-laser.html`.
2. Pégalo en tu módulo de código o súbelo a tu servidor.
3. Asegúrate de verificar el correo de activación de FormSubmit en `hola@jkwilches.com` tras el primer envío.
